# LittleLemon-Capstone
This repository contains the final database architecture, Python client integration, and data visualization deliverables for the Little Lemon capstone project.

Project Files Included:
LittleLemonDB.sql: The exported MySQL database schema, including all tables and stored procedures.

main.py: The Python script used to connect to the database and execute booking procedures.

ER_Diagram: The Entity-Relationship diagram detailing the database structure and table relationships.

Interactive Data Dashboard
The final sales reports, customer sales data, and profit trends were generated using Tableau.
